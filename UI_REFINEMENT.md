# DukaFlow UI Refinement

The frontend was refined to match the supplied DukaFlow visual reference more closely.

Key changes:
- Unified navy/blue SaaS visual system.
- Refined sidebar, navigation groups, active state, and branding.
- Refined sticky topbar, search, notification control, user/role presentation.
- Reworked cards, shadows, borders, spacing, typography, tables, forms, buttons, modals, and states.
- Fixed Business Settings layout so the profile/security cards no longer collapse into narrow columns.
- Reworked Subscription Plans layout with full-width three-column pricing cards on desktop and responsive stacks on mobile.
- Improved Dashboard metric sizing and responsive grids.
- Improved legacy purchase form styling and utility layouts.
- Improved mobile layout and bottom navigation presentation.
- Refined splash screen using the supplied DukaFlow branding direction.
- Added page-aware CSS hooks from `auth.js` for consistent per-page styling.

No secrets or `.env` files are included in the package.
